## 🚀 使用与提交规范

```bash
# 1. 进入仓库
cd ncu-course-portfolio

# 2. 查看当前改动
git status

# 3. 添加改动并提交
git add .
git commit -m "feat(week01): 完成第1周实验"

# 4. 推送到 GitHub
git push
```

**提交信息建议格式：** `类型(范围): 说明`
- `feat` 新功能 / 新增实验
- `fix` 修复错误
- `docs` 文档更新
- `chore` 杂项（配置、清理）
